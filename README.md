# Daramadsazan Project 02 — Social Growth Platform

MVP for compliant social-media growth and content operations.

## Included in this first browser MVP
- Persian RTL responsive dashboard
- Create, list, and delete content drafts
- Select target platform and optional publication date
- Browser-local persistence
- AI assistant interface placeholder

## Not yet connected
- Authentication, workspace roles, and server database
- Official OAuth integrations
- Scheduled publishing and live analytics
- AI model/API and subscription billing

Drafts stay in the current browser only. No fake followers, likes, views, or automated engagement. Never put access tokens in frontend code.

## Roadmap
1. Secure backend API, database, accounts, roles, and audit log
2. Official platform integrations with least-privilege OAuth scopes
3. Durable publishing queue with rate-limit handling and retries
4. Analytics ingestion and transparent growth reports
5. Subscription plans and agency workspaces
